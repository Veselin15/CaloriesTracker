# 🥗 CaloriesTracker

[![Website](https://img.shields.io/badge/Live%20Site-caloriestracker--yy3h.onrender.com-brightgreen?style=flat-square&logo=django)](https://caloriestracker-yy3h.onrender.com)

CaloriesTracker is a modern web application that helps you track your daily calorie intake, manage your nutrition goals, and gain insights into your eating habits.  
Built with Django, PostgreSQL, and a custom user system, it provides a secure, user-friendly platform for anyone looking to improve their health and wellness.

🌐 **Live Demo:** [caloriestracker-yy3h.onrender.com](https://caloriestracker-yy3h.onrender.com)

---

## ✨ Features

- 👤 **User Registration & Authentication**  
  Secure sign-up, login, and profile management with a custom user model.

- 🍽️ **Food Entry Management**  
  Add, edit, and delete food entries with nutritional information.

- 📅 **Daily & Historical Tracking**  
  View your calorie and macro stats by day, week, or custom range.

- 📊 **Visual Insights**  
  Beautiful dashboards and charts to help you understand your eating patterns.

- 🔍 **Food Search**  
  Search for foods and auto-fill nutrition data using the FatSecret API.

- 🗄️ **PostgreSQL Database**  
  Robust, production-ready data storage.

- 🎨 **Modern UI**  
  Responsive design with Bootstrap and custom CSS for a seamless experience on any device.

- 🔒 **Environment Variable Management**  
  Securely store sensitive credentials using a `.env` file.
